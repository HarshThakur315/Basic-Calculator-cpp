# Basic Calculator (C++)

A menu-driven C++ calculator for addition, subtraction, multiplication and division.

## Features
- Menu-driven interface
- Addition, subtraction, multiplication and division
- Division-by-zero validation
- Input validation and repeat calculations

## Run the C++ program
```bash
g++ main.cpp -o calculator
./calculator
```
On Windows:
```bash
g++ main.cpp -o calculator.exe
calculator.exe
```

## Colourful web preview
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from a branch → main → /root → Save).

**Note:** The web preview is an interactive visual demonstration. The required menu-driven C++ implementation is in `main.cpp`.
